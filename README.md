# Experiment with Three.js

I wanted to try out **Three.js** and see what it’s like to work with 3D graphics in the browser.  
Most of this project was created with the help of **AI**, so it’s more of a fun experiment than a polished project.

## Idea

- Learn how to set up scenes, objects, and animations  
- No big structure, just testing and experimenting  

## Note

This is more of a **playground** than a serious project.  
If you look at the code, you’ll see a mix of AI suggestions and my own tweaks.  
It’s meant to be playful and experimental. 😄
